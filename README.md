# 📊 WhatsApp Chat Analyzer

A data science web app built using **Python and Streamlit** that analyzes WhatsApp chat exports and provides interactive insights and visualizations.

---

## Features

-Message trend analysis (daily & monthly timelines)
-Most active users in group chats
-Word frequency analysis
-Emoji usage insights
-Interactive visual dashboard using Streamlit

---

## Tech Stack

- Python 
- Pandas 
- Matplotlib 
- Streamlit 
- Regex 

---

## How to Use

1. Export your WhatsApp chat as a `.txt` file  
2. Run the Streamlit app  
3. Upload the chat file  
4. View insights on dashboard  

---

## Privacy Note

Chat data is not included in this repository to protect user privacy.
