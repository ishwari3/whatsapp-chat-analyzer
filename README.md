# WhatsApp Chat Analyzer 📊

A data science project that analyzes WhatsApp chat data and extracts meaningful insights.

## Features
- Most active users
- Message frequency analysis
- Basic data visualization

## Tech Stack
- Python
- Pandas
- Matplotlib

## How to Use
1. Export your WhatsApp chat as a .txt file
2. Place it in the project folder
3. Run the script

## Note
Chat data is not included for privacy reasons.
